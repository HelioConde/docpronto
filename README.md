# DocPronto

Protótipo focado em propostas e orçamentos para prestadores de serviço. Preenche dados do cliente, escopo, valor, prazo e condições, calcula a prévia e permite imprimir/salvar como PDF pelo navegador.

Os documentos não substituem contratos nem aconselhamento jurídico. Pagamentos e exportação PDF avançada não estão conectados.
