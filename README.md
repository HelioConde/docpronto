# DocPronto

Protótipo de propostas e orçamentos para prestadores de serviço. Permite cadastrar cliente, prazo, condições e contato comercial opcional; detalha até 10 serviços ou materiais com quantidade e preço unitário, calcula o total e define a validade da proposta (sugerida em 15 dias). É possível imprimir ou salvar a proposta como PDF.

As propostas recentes ficam salvas apenas no navegador usado para criá-las. O histórico permite reabrir, editar e excluir propostas. Os dados continuam locais: não há contas, backend, pagamentos ou sincronização entre dispositivos. Propostas não substituem contratos nem aconselhamento jurídico.
